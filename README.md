# ずんだもんAI

高槻市の AI エンジニア。現場で働きながら、**業務の仕組みを一人で、設計から本番運用まで**作っています。
作った道具のうち、外の人にも使える物は、無料で公開しています。

## 公開している道具

| 道具 | ひとこと |
| :-- | :-- |
| [返信サポート by ずんだもんAI](https://github.com/tashirosmasashis-cell/line-reply-helper) | LINE 公式アカウントの管理画面で、会話をまるごと読み、まだ返していないメッセージに漏れなく応える返信の案を作る Chrome 拡張。会話を開かずに読める（既読が付かない）・相手ごとの話し方・分からない事実は［要確認］で空ける |

## 仕事で作ってきた物

公共施設の公式サイト・予約と業務の管理・AI で紙を読み取る仕組み・QR コードのタイムカード・LINE の予約と自動返信などを、一人で設計し、いまも本番で毎日使われています。
画面は、架空のデータでサイトに公開しています（コードは職場の物なので非公開です）。

→ **[サイト（実績・デモ・ブログ）](https://zunda.tsutsumicommunity.org)**　・　[事業者の方へ](https://zunda.tsutsumicommunity.org/for-business)

## 使っている物

Astro ／ Cloudflare Workers ／ Supabase ／ LINE Messaging API ／ Gemini・Claude ／ Chrome 拡張（Manifest V3）
